# Execution Guide for CNN Image Segmentation

This guide outlines the prerequisite setup, dependencies, and step-by-step instructions required to execute both [`cnn_segmentation.py`](file:///d:/DL/cnn_segmentation.py) and [`test.py`](file:///d:/DL/test.py).

---

## 1. Prerequisites & Environment Setup

Before running either script, ensure your Python environment is configured with the necessary dependencies.

### Step 1.1: Verify Python Installation
Verify that Python (3.9 to 3.12 recommended) is installed:
```powershell
python --version
```

### Step 1.2: Activate the Virtual Environment
A virtual environment (`.venv`) is already present in the workspace. Activate it based on your terminal:

- **PowerShell**:
  ```powershell
  .\.venv\Scripts\Activate.ps1
  ```
  *(If PowerShell displays an execution policy restriction error, run: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` and retry)*

- **Command Prompt (CMD)**:
  ```cmd
  .\.venv\Scripts\activate.bat
  ```

*(Optional: If you need to re-create the virtual environment from scratch:)*
```powershell
python -m venv .venv
```

### Step 1.3: Install Required Dependencies
Ensure all libraries needed across both scripts are installed in the active environment:
```powershell
pip install tensorflow numpy matplotlib pillow
```

#### Dependency Breakdown:
| Package | Required By | Purpose |
| :--- | :--- | :--- |
| `tensorflow` | Both | CNN model architecture, training, and prediction |
| `numpy` | Both | Array manipulation, reshaping, and numeric operations |
| `pillow` | `cnn_segmentation.py` | Synthetic image creation & ground-truth mask drawing |
| `matplotlib` | `cnn_segmentation.py` | Visualizing input, ground truth, and predicted segmentation masks |

## 2. File 1: `cnn_segmentation.py`

### Overview
This script creates a synthetic 64×64 pixel image containing a white circle on a black background and its corresponding binary mask. It then trains an encoder-decoder style CNN for 10 epochs and displays the visual segmentation output using Matplotlib.

### Pre-Execution Checklist
- [x] Dependencies (`tensorflow`, `numpy`, `matplotlib`, `pillow`) are installed.
- [x] A GUI/display environment is available (since `plt.show()` opens an interactive window).

### Execution Command
```powershell
python cnn_segmentation.py
```
*(Or `py cnn_segmentation.py`)*

### Expected Output
1. **Model Training Progress**:
   TensorFlow will log training progress for 10 epochs showing binary crossentropy loss and accuracy.
2. **Interactive Visualization Window**:
   A Matplotlib window will pop up with 3 side-by-side subplots:
   - **Original Image**: The grayscale circle image.
   - **Actual Mask**: The ground truth circle mask.
   - **Predicted Segmentation**: The predicted binary mask generated by the CNN.
   *(Close the image window to allow the script to exit).*
3. **Console Confirmation**:
   ```text
   CNN Image Segmentation Completed Successfully
   ```

## 3. File 2: `test.py`

### Overview
This script demonstrates an end-to-end convolutional segmentation workflow on a synthetic batch of 100 images (64×64×1). It defines an Encoder-Decoder CNN architecture with 2 downsampling pooling layers and 2 upsampling layers, trains for 3 epochs with batch size 8, and evaluates output dimensions.

### Pre-Execution Checklist

- [x] Virtual environment is activated.

### Execution Command

python test.py

## 4. Troubleshooting & Notes

- **TensorFlow oneDNN / CUDA Info Warnings**:
  Messages such as `I tensorflow/core/platform/cpu_feature_guard.cc...` are standard TensorFlow informational notices indicating CPU optimizations and do not represent errors.
- **Headless Environments**:
  If running on a server without a display and executing `cnn_segmentation.py`, Matplotlib might raise a display error. You can save plots to disk instead by replacing `plt.show()` with `plt.savefig("segmentation_output.png")`.
